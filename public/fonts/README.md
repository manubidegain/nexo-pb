# Fuentes

Coloca los archivos de la fuente Eastman en este directorio:

- Eastman-Regular.woff2
- Eastman-Regular.woff
- Eastman-Bold.woff2
- Eastman-Bold.woff

Si no tienes los archivos de la fuente Eastman, puedes:
1. Comprarla/descargarla de una fuente oficial
2. O usar una fuente alternativa similar editando el archivo `app/globals.css`
